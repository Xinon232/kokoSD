Loading Koko (32 MB)

Press Enter or click the screen to start. Type on your keyboard or click the keys. Enter send (START) Tab first suggestion (L) Shift+Tab second (R) Esc stop (B). The page-with-a-plus key starts a new chat; the book key turns the fact table and calculator off and on.

This is the cartridge's own screen, 240 by 160 pixels, drawn by the same code with the same model and arithmetic, running in your browser. Replies marked with a small book come from a built-in table of Simple English Wikipedia opening sentences, and those marked with an equals box are calculated; everything else is the model, which is tiny and often gets facts wrong.
